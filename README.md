# Engineering Data Analytics Portfolio

## Overview

This portfolio demonstrates engineering data analytics through two case studies:

1. NASA Turbofan Engine Sensor Health Analysis
2. Renewable Energy Resource Comparison Across U.S. Regions

## Objectives

- Analyze engineering datasets using Python
- Create professional data visualizations with Matplotlib
- Apply statistical analysis to real engineering problems
- Communicate engineering insights through technical reports

## Tools

- Python
- pandas
- NumPy
- Matplotlib
- Jupyter Notebook
